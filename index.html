01

Recommended customer flow

From enrollment to verified payment

  1. Customer completes the enrollment form.
  2. Browser validates the required fields.
  3. Website inserts an enrollment record into Supabase.
  4. Supabase returns a unique enrollment ID.
  5. Website reveals or enables the Stripe Buy Button.
  6. Website passes the enrollment ID to Stripe as client-reference-id.
  7. Customer completes checkout on Stripe’s hosted payment page.

Version one boundary

Do not overstate payment status.

A successful form submission does not prove payment. Payment status should remain not_verified until a signed Stripe webhook is processed server-side.

02

Data model

Collect only what the enrollment needs.

Recommended enrollment fields

  • First name
  • Last name
  • Email
  • Company
  • Product or plan selection
  • Consent accepted
  • Enrollment status
  • Payment status
  • Created timestamp

Information the site must not collect or store

  • Card number
  • CVV
  • Bank-account credentials
  • Stripe secret key
  • Supabase service-role key
  • Database password
