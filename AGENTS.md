# Project instructions
- Build a static site compatible with GitHub Pages.
- Do not add a Node.js server or build step.
- Use semantic HTML and accessible labels.
- Keep Supabase and Stripe secret keys out of browser code.
- Never collect payment-card information in the enrollment form.
- Use only browser-safe Supabase and Stripe publishable keys.
- Keep configuration values in one clearly labeled section.
- Update README.md whenever setup behavior changes.
